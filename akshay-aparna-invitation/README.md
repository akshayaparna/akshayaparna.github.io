# Akshay Shaji & Aparna Aji — Wedding Invitation

Static HTML/CSS/JS invitation designed as a ChungDoi-style single-page wedding invitation.

## Run locally

Open `index.html` directly, or use VS Code Live Server.

## Add photographs

Put your photographs in:

assets/images/photo-1.jpg
assets/images/photo-2.jpg
assets/images/photo-3.jpg
assets/images/photo-4.jpg

## Add music

Put an MP3 at:

assets/music/wedding.mp3

Browsers normally require the first user interaction before music can play. The Open button is used for that interaction.

## Hosting

This project can be deployed directly to:
- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

No PHP or database is required for the current static version.

## Important

The visual structure and interaction are recreated from the public reference invitation, but the implementation and decorative CSS are original rather than copying ChungDoi source code or proprietary assets.
